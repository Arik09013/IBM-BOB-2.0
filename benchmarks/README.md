# Benchmarks

This directory contains synthetic benchmark repositories and datasets for
reproducible research experiments.

## Structure

- `repositories/` — Small synthetic Python/JS repos used as test subjects.
  Added in Phase 1.
- `datasets/`     — Experiment configuration files (BenchmarkConfig JSON).
  Added in Phase 1.
- `results/`      — Run output files (metrics.jsonl). Gitignored except
  aggregated summaries.

## Data policy

All benchmark data is synthetic or taken from public-domain sources.
No personal, confidential, client, or social-media data is used.
